SYLLABUS_ID: 1
CLASS_ID: 1004
COURSE: CST 161 - Computer Programming Fundamentals (4 credits)
MAJOR: A.S. Data Science
DEPARTMENT: STEM
INSTRUCTOR: Alan Greene

DESCRIPTION:
An introduction to problem solving, algorithmic thinking, and the fundamentals of programming using Python. Students learn variables, data types, decision structures, loops, basic data structures, file I/O, number systems, and introductory object-oriented programming. The course emphasizes computational reasoning and the foundations needed for advanced computer science coursework.

LEARNING OUTCOMES:
Write and run Python programs to solve computational problems.
Understand and apply variables, expressions, and selection structures.
Use loops and iterative problem-solving techniques.
Work with lists, dictionaries, and other basic data structures.
Perform file input/output operations in Python.
Explain the basics of number systems and digital logic.
Design programs using functions and simple classes.
Demonstrate professional coding habits and debugging strategies.

GRADING POLICY:
Homework – 20%
Labs – 20%
Projects – 20%
Quizzes – 10%
Exams – 30%

SYLLABUS_ID: 2
CLASS_ID: 1003
COURSE: MAT 171 - Unified Calculus I (4 credits)
MAJOR: A.S. Data Science
DEPARTMENT: STEM
INSTRUCTOR: James Patel

DESCRIPTION:
A first course in differential and integral calculus with emphasis on limits, continuity, differentiation, curve analysis, and introductory integration techniques. Students learn to model real-world phenomena, analyze change, and apply calculus concepts to physics, engineering, and data-driven disciplines.

LEARNING OUTCOMES:
Evaluate limits analytically and graphically.
Determine continuity and understand behavior near points and asymptotes.
Differentiate a wide range of algebraic and transcendental functions.
Apply derivatives to optimization, related rates, curve sketching, and motion.
Use the Mean Value Theorem and other analytic tools.
Compute antiderivatives and definite integrals.
Apply the Fundamental Theorem of Calculus.
Model real-world problems using calculus concepts.

GRADING POLICY:
Homework – 20%
Quizzes – 15%
Unit Exams – 40%
Final Exam – 25%
